description_en = '''
For general/non-bOdhAyana (kRSNa) Yajurveda zAkhA-s (eg. Apastamba, taittirIya). Date is computed in code (`UpakarmaFestivalAssigner.assign_yajurveda_upakarma`, in jyotisha) rather than by this file: the chain zrAvaNa-pUrNimA -> bhAdrapada-pUrNimA -> ASADha-pUrNimA (each at ghatikA 12, start of madhyAhna, paraviddha) is checked in order, and the first one with no eclipse (before relative ghatikA 45), saGkramaNa, or zukra-mAudhya flaw is used. If all three are flawed: a mAudhya-only flaw on zrAvaNa-pUrNimA is remediable, so it is used anyway, performed zAntipUrvakam (`yajurvEda-upAkarma~zAntipUrvakam`); but an eclipse/saGkramaNa flaw on zrAvaNa-pUrNimA has no such remedy, so bhAdrapada-pUrNimA (the first switch in the chain) is used instead, accepted despite its own flaws. See also `zukla-yajurvEda-upAkarma` (zukla Yajurveda; switches to zukla-paJcamI instead) and `bOdhAyana-yajurvEda-upAkarma` (bOdhAyana zAkhA; chain is zrAvaNa -> ASADha -> bhAdrapada instead).
