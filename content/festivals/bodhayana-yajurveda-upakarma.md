description_en = '''
For followers of the bOdhAyana zAkhA of the kRSNa-yajurveda. Date is computed in code (`UpakarmaFestivalAssigner.assign_bodhaayana_upakarma`, in jyotisha): the chain zrAvaNa-pUrNimA -> ASADha-pUrNimA -> bhAdrapada-pUrNimA (each at ghatikA 12, start of madhyAhna, paraviddha; note ASADha comes before bhAdrapada here, unlike the general yajurvEda-upAkarma rule) is checked in order, and the first one with no eclipse (before relative ghatikA 45), saGkramaNa, or zukra-mAudhya flaw is used. If all three are flawed: a mAudhya-only flaw on zrAvaNa-pUrNimA is remediable, so it is used anyway, performed zAntipUrvakam (`bOdhAyana-yajurvEda-upAkarma~zAntipUrvakam`); but an eclipse/saGkramaNa flaw on zrAvaNa-pUrNimA has no such remedy, so ASADha-pUrNimA (the first switch in this chain) is used instead, accepted despite its own flaws.
'''
